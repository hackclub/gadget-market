# Design Requirements

## Before starting your project

Make a GitHub Repo! Make sure to have frequent commits of your work so that we can verify it's your own.

Time tracking options:
- Journaling (recommended)
    - Make sure you have at least 1 screenshot per session entry!
- Lapse
- Lookout

## Quality

Because the projects submitted to Gadget Market will be traded with others, the quality bar for projects of this program will be higher than usual.

That means:
- Projects need to be polished! Round your corners, add silkscreen art, remove empty space from the PCB, etc!
- Projects must be unique in some way! Don't just ship another macropad.
- Projects must serve a purpose. It could be whimsical (ie: something that makes capacitors explode), or simple (ie: capacitive touch PCB keychain with backlit LEDs) but don't just make LEDs light up on a giant PCB!

This is not an extensive list! It is up to the reviewer if they want to approve the project.
