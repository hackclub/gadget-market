# Funding

## things you can do to get a shipping grant

**Already have some extra PCBs lying around?** Want to trade projects with others but need a grant to ship it? Here are a couple ways you can get it through Gadget Market!

*Note: your project must be approved to be on the market before receiving the grant.*

Write code for your hardware project!

* Must be hackatime tracked
* Grants are quality based: the longer the interaction with your program, the more the grant will be (more info on exact numbers later) 
    * Simple programs (ie: rubber ducky stuff where you plug it in and it types a few keys) → not worth a lot
    * Complex (ie: games, see also: the games that were submitted to hackapet) → worth a lot
* Write code for your own hardware project or someone else's that you physically have on you!
* You'll need to take a video demo of what you made running on the hardware

Build your hardware project

* NOTE: your project cannot be submitted to a program that is currently running
    * ie: you can submit a Highway project you never built, but not a Fallout project
    * the build hours could not have been submitted to a previous program 
* journal / lapse your building time
* you must submit a demo video to prove that it works 

Make a site for your project

* Showcase it! Market it! Like a magazine page but site format. Basically a project page of sorts.
