# Getting Started

Welcome! 

Here's how Gadget Market works:

1. design a hardware project!
2. get it made and built irl!
3. list the extra PCBs you have on the gadget market!
4. scroll around - when you see another project you want to trade with, DM the other person!
5. if they accept the trade, mail your project to the other person as they mail it to you!
