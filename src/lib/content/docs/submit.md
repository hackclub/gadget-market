# How to Submit

This page is on how to submit in order to get funding to build your project! 

- Looking to list a Gadget Market project on the Market? Read [How to List](/docs/list)
- Looking to trade an existing PCB? Read [Existing PCBs](/docs/skip)

The design of your project needs to be fully shipped before you submit it! That means your GitHub repo and project need to be polished.

## Repo requirements

In your GitHub repo, make sure you have all source files of your project:
- kicad.pro, kicad.sch, kicad.pcb, and gerber + drill files of your board
- if there's any CAD: .STEP file of your project's 3D CAD model (and source design file format as well - .f3d, .FCStd, etc)
- basic firmware (you can update this later when you have your board)
- anything else that you used (libraries, references)

In the README.md of your repo, include:
- title of project at top
- description of project
- screenshots of the schematic, PCB, and 3D view of your board!
- If your project has any CAD: screenshots of it assembled (with your PCB) 
- Bill of materials (a table of parts you used - include name, quantity, price, and source!)
- NO AI GENERATED TEXT IS ALLOWED

## How do I submit? 

**Ship it in the [#gadget-market-ships](https://hackclub.enterprise.slack.com/archives/C0BNTG07VU0) channel on Slack!**

In your message, make sure you include:
- GitHub repo link
- Screenshot of your schematic, PCB, and 3d view of the PCB
- Description explaining what your project does!
- Which tier of funding you're submitting for (Simple, Medium, Complex, or more)
- How much your project costs in total

After a reviewer reacts with the ✅ emoji, it’s approved! We'll send you a form to fill out, to get your grant to order your parts.
